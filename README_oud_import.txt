大津線 記録管理 v6 - 公開時刻表 .oud 読み込み

【追加・修正内容】
・OuDia 1.00 / 1.02 のブロック構造に沿って駅・ダイヤ・列車を解析します。
・上り列車の駅順を正しく反転して表示します。
・到着時刻と発車時刻の両方を保持して表示します。
・備考欄（Bikou）は読み込みません。
・反映前に追加・変更・削除・変更なしの件数を表示します。
・既存の記録一覧、編集、完了/未完了、CSV、ログイン、現在地機能には触れません。

【導入手順】
1. Supabase SQL Editorで public_timetable.sql を1回実行。
2. GitHubで index.html / app.js / style.css / hero-805.jpg を同名ファイルで置き換えてコミット。
3. config.js は変更せず、そのまま残す。
4. 管理者でログインし、「公開時刻表」から .oud を選択。
5. 「ファイルを解析」で差分を確認し、「この時刻表を共有データに反映」で確定。
6. 閲覧者アカウントで公開時刻表が見えることを確認。

注意：この機能は公開時刻表の閲覧・管理用です。既存の記録と完了状態は変更しません。
